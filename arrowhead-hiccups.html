此处用均值差解释“角点评分”。原版还组合符号一致性与方差，并用 dynamic programming 复用区域统计，再进行筛选。

为什么会出现箭头？

对上三角（d > 0）的 domain [a,b]，当 i 靠近左边界时，i−d 先离开 domain，而 i+d 仍在里面，得到负值；靠近右边界时则相反，得到正值。两片三角区域共同形成 arrowhead。它反映沿整段区间的结构，不要求角点本身具有 loop peak。

候选负三角的顶点是 (a,a)、(a,b)、((a+b)/2,b)；正三角的顶点是 ((a+b)/2,b)、(b,b)、(b,2b−a)。这里括号表示 (行,列)。页面按像素中心采样三角区域。下三角沿主对角线镜像展示上三角结果；点击 (j,i) 时查看对应的上三角计算 (i,j)。

教学边界：M* 是直接生成的模拟平衡后接触强度，未执行 KR balancing。箭头变换按论文公式逐点计算；Cdemo、候选范围与局部最大值筛选是教学简化，不能作为原版 Arrowhead 的 domain calls。

四种背景各排除什么？统计步骤怎样简化？

Donut：周围环状背景，排除中心方块与中心十字线。Lower-left：朝向对角线的左下区域，帮助识别同一 domain 内的广泛富集。Horizontal / Vertical：宽 3 bins 的横向 / 纵向条带，避免把整行或整列的高信号误当成孤立 peak。所有 mask 都排除半径 p 的中心方块。

本例固定使用解析距离背景 E(d)=120/(d+2)0.7+2，逐个候选计算 Poisson 上尾 P(X≥O)，再对每种 mask 的全部可检验候选分别做 Benjamini–Hochberg 校正。四种 O/λ 与 q 都通过时才标记 enriched pixel。q 是教学值，不是原版 HiCCUPS 的 FDR 输出。

本例只测试完整窗口完全位于上三角内的像素；窗口触边或过于靠近对角线的位置不参与检验。第④步用 8 邻接合并示意去重；真实 HiCCUPS 还有按期望分层的 FDR 阈值估计、过滤、centroid 聚类与跨分辨率合并。页面不能输出可用于生物学结论的 loop calls。

教学边界：矩阵、domain、条带与 loop 均为模拟。局部背景的距离校正与四 mask 联合判断保留核心逻辑；Poisson + BH、统一富集门槛和 8 邻接合并是教学替代。
